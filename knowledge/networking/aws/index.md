# AWS Networking Components

* [AWS Basic Networking](basic.md) - Standard Databricks-ready VPC with NAT egress and S3/STS/Kinesis endpoints.
* [AWS Firewall Networking](firewall.md) - VPC with AWS Network Firewall for fine-grained egress filtering.
* [AWS Exfiltration Protection](exfiltration-protection.md) - Hub-spoke with Transit Gateway + Network Firewall, optional PrivateLink.
* [AWS Multi-Workspace PrivateLink](multi-workspace-privatelink.md) - Shared VPC with backend PrivateLink for multiple workspaces.
* [AWS Serverless PrivateLink](serverless-privatelink.md) - NCC + NLB + Endpoint Service for serverless compute egress.
