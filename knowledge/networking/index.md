# Networking Components

Workspace networking components, organized by cloud. Each cloud offers a range from a simple baseline to fully isolated/private-connectivity tiers.

# Clouds

* [aws/](aws/) - VPC, Network Firewall, Transit Gateway, and PrivateLink patterns (5 components).
* [azure/](azure/) - VNet injection, Azure Firewall, and Private Link tiers (5 components).
* [gcp/](gcp/) - BYOVPC, Private Service Connect, and Shared VPC patterns (3 components).

See [Sovereign & Regulated Cloud Support](/sovereign-clouds.md) for GovCloud / government-region considerations.
